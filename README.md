# Academic Research Workspace

科研工作空间 — 用于论文撰写、文献管理、数据分析和项目协作。

## 目录结构

```
├── papers/           # 论文草稿（按项目/期刊分类）
├── literature/       # 文献笔记与阅读记录
├── data/             # 实验数据与分析结果
├── code/             # 分析脚本与代码
├── templates/        # 各类模板
└── .github/workflows/ # 自动化工作流
```

## 使用说明

1. **文献检索**：在 `literature/` 中按主题创建笔记
2. **论文撰写**：在 `papers/` 中创建项目子目录
3. **数据分析**：代码放 `code/`，数据放 `data/`
4. **版本管理**：每次重要进展提交一次 commit

## 模板

- `templates/paper-template.md` — 论文结构模板
- `templates/literature-note-template.md` — 文献精读笔记模板
